# Quill for Windows

Windows x64 installers and signed updates for the Quill writing assistant.

[Download the latest release](https://github.com/jccidc/quill-releases/releases/latest).

Install version 0.1.3 or later once to enable future in-app updates. Quill checks for updates automatically; review the notes and choose **Install and restart** when ready. Older installers do not have an updater.

Your Claude API key and preferences remain on your computer. Downloads contain no account key or personal settings. See the included INSTALL.txt for setup and privacy options.

This is a beta. Update packages are cryptographically verified, but the installer does not yet have a Windows publisher certificate. Editor compatibility depends on Windows accessibility support.

This repository contains release downloads only. Application source is maintained separately.
